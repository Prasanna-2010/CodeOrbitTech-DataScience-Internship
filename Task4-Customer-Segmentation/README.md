# Task 4 - Customer Segmentation Using K-Means

## 📌 Project Overview

This project focuses on customer segmentation using the K-Means clustering algorithm.

The Superstore Sales dataset is used to group customers according to their purchasing behavior. Customer-level features such as total spending and purchase frequency are calculated and used for clustering.

The objective is to identify meaningful customer segments that can help businesses understand their customers and develop targeted strategies.

---

## 🎯 Objectives

- Prepare customer-level data.
- Calculate total spending for each customer.
- Calculate purchase frequency for each customer.
- Standardize the selected features.
- Determine an appropriate number of clusters using the Elbow Method.
- Apply K-Means clustering.
- Visualize the resulting customer segments.
- Analyze the characteristics of each cluster.
- Derive useful business insights.

---

## 📊 Dataset

**Dataset:** Superstore Sales Dataset

The dataset contains transaction-level information about customers, orders, products, categories, regions, and sales.

For this project, transaction-level records were aggregated to create customer-level features.

### Features Used

**Total Spending**

The total sales generated by each customer.

**Purchase Frequency**

The number of unique orders associated with each customer.

## 🔍 Methodology

### 1. Customer-Level Aggregation

The transaction data was grouped by `Customer ID`.

Two features were calculated:

```python
Total_Spending
Purchase_Frequency
```
### 2. Feature Selection

The following features were selected for clustering:
```python
X = customer_data[
    ["Total_Spending", "Purchase_Frequency"]
]
```
### 3. Feature Standardization

The features were standardized using StandardScaler.

This prevents features with larger numerical values from dominating the clustering process.

### 4. Elbow Method

The Elbow Method was used to determine a suitable number of clusters.

The inertia was calculated for different values of K.

Based on the resulting elbow curve, 3 clusters were selected.

### 5. K-Means Clustering

K-Means was applied using three clusters.
```python
kmeans = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)
```
Each customer was assigned to one of the three clusters.

## 📊 Cluster Analysis

The analysis produced three customer segments.

- Segment	Customers	Average Spending	Average Purchase Frequency
- Regular High-Value Customers	292	3035.24	8.36
- Occasional Low-Value Customers	422	1603.31	4.35
- Premium Customers	79	8843.63	8.16
- Cluster 0 - Regular High-Value Customers

This segment contains customers who have relatively high spending and frequent purchases.
These customers are valuable and can be encouraged to increase their spending through personalized offers and loyalty programs.

- Cluster 1 - Occasional Low-Value Customers

This is the largest customer segment.
These customers have lower average spending and purchase less frequently compared with the other segments.
Targeted promotions and personalized recommendations could help increase their purchase frequency.

- Cluster 2 - Premium Customers

This segment contains customers with the highest average spending and high purchase frequency.
These customers represent the most valuable customer group and should receive strong retention and loyalty strategies.

## 💡 Business Insights

Customer segmentation can help businesses develop targeted strategies instead of treating every customer the same.
Possible strategies include:
- Providing loyalty rewards to Premium Customers.
- Offering personalized recommendations to Regular High-Value Customers.
- Using discounts and promotional campaigns to encourage Occasional Low-Value Customers to purchase more frequently.
- Prioritizing customer retention for high-value segments.
