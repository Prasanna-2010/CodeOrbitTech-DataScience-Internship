## 📚 Tasks Completed

### Task 1 - Data Cleaning & Exploration

**Technologies:** Python, Pandas, NumPy

Performed data cleaning and preprocessing on the Superstore Sales dataset.

Key activities:

- Dataset inspection
- Missing value analysis
- Duplicate detection
- Data type correction
- Date conversion
- Statistical analysis
- Categorical data analysis

### Task 2 - Exploratory Data Analysis

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn

Performed exploratory analysis to identify patterns, trends, distributions, and relationships within the Superstore Sales dataset.

Key activities:

- Statistical analysis
- Sales distribution analysis
- Category analysis
- Regional analysis
- Data visualization
- Pattern identification
- Outlier analysis

📁 [View Task 2](./Task2-EDA/)

---

### Task 3 - Simple Linear Regression

**Technologies:** Python, Pandas, NumPy, Matplotlib, Scikit-learn

Implemented a Simple Linear Regression model to study the relationship between order timing and sales.

Key activities:

- Feature engineering
- Train-test split
- Linear Regression
- Prediction
- MAE calculation
- MSE calculation
- RMSE calculation
- R² evaluation
- Regression visualization

📁 [View Task 3](./Task3-Linear-Regression/)

---

### Task 4 - Customer Segmentation

**Technologies:** Python, Pandas, NumPy, Matplotlib, Scikit-learn

Implemented K-Means clustering to segment customers based on purchasing behavior.

Customer-level features included:

- Total Spending
- Purchase Frequency

The Elbow Method was used to determine the appropriate number of clusters.

Three customer segments were identified:

- Regular High-Value Customers
- Occasional Low-Value Customers
- Premium Customers

📁 [View Task 4](./Task4-Customer-Segmentation/)
